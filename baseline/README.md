# Immutable v1 source-fixture subset

This repository contains **10 original text/code/key files**, copied byte-for-byte
from the 30 October 2026 v1 starter. `BASELINE_LOCK.json` is a new, explicitly named
**subset** manifest; it does not pretend to be the full original 17-file manifest.
The full original archive and earlier private packages remain preserved separately.

Included: published v1 JSON, original decoder, original First Program source and
transcription, four reading inscriptions plus their answer file, and original
source/credit note. Original notes may reference PDFs that are deliberately not
included here. There are no PDFs, private/public conversation transcripts, whole
ZIP archives, account records or source-capture dumps in this repository.

These archived source files retain their original notices/terms. New MIT coverage
of current v2 code/data does not silently rewrite the archived v1 files. The old
decoder's opt-in `--run` remains in its original bytes, but tests only call decode.
Use the new root-level codec, which has no execution option.
