PUBLISHED CONTENT SAVED AS PLAIN TEXT
reference/cavescript32-v1.0-key.json
The complete copyable JSON block, saved unchanged as UTF-8 (HTML character
references decoded, no mapping changes), from:
https://suposystem.ai/cavescript/public-key/#character-tables

examples/READ.txt, OPEN.txt and SAMPLE.txt
The existing pair sequences from the first-word example, four-character
challenge and sample inscription at:
https://suposystem.ai/cavescript/learn-to-read/
READ is assembled in cell order from the four published table rows.
examples/ASK.txt is the three-pair example on worksheet page 2.
The token files have one file-ending newline for plain-text convenience;
this does not add an encoded newline to the example messages.
